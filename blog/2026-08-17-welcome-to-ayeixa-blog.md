This is the public engineering blog for AYEIXA.

It is hosted on a zero-cost GitHub Pages URL while `ayeixa.com` domain authority is not yet proven. This host is **not** `ayeixa.com/blog`.

<!--truncate-->

## What this blog is for

- Technical notes on AYEIXA open-source utilities
- Architecture decisions that can be checked against public repositories
- Corrections, when needed, with an auditable record

## What this blog will not do

- Fabricate users, customers, traffic, or case studies
- Publish secrets or personal data
- Make technical claims without a checkable source

Public repositories currently include [FuelLite](https://github.com/alpallovy/ayeixa-fuellite), [OpenCoordinator](https://github.com/alpallovy/ayeixa-open-coordinator), [MCP Guardian](https://github.com/alpallovy/ayeixa-mcp-guardian), [Sentience Eval](https://github.com/alpallovy/ayeixa-sentience-eval), and [Agent Memory Spine](https://github.com/alpallovy/ayeixa-agent-memory-spine).
